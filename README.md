# EDA_and_Visualisation_in_Python
## Project Overview
Exploratory Data Analysis & Visualisation in Python using Matplotlib and Pandas.
## Project Process
The dataset (Tech Registration Dataset) was initially messy and required thorough data cleaning. Data cleaning was performed in Python using Pandas to handle duplicates, missing values, inconsistent formats, and incorrect data types.
After cleaning, Matplotlib was used for visualization to explore patterns and generate insights. The analysis focused on:
- The most registered training packages
- The LGA with the highest number of registrations
- The age range with the most interest in the tech training
- Monthly registration trends
A visualization was also created to compare the month of submission against training packages.
## Objectives
- To identify the most preferred training package
- To determine the LGA with the highest registration
- To analyze the age range with the highest participation
- To examine the months during which registrations occurred
## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
## Key Insight
- Cybersecurity was the most preferred training package, with the highest number of registrations across all LGAs except Gokana, where Digital Marketing had the highest registrations.
- Khana LGA recorded the highest number of registrations, with 106 participants.
- The 31–35 age range (mature adults) showed the highest level of interest, with 74 registrations across all LGAs.
- Registrations occurred between July and August, with the majority (167 out of 188 registrations) taking place in July.
